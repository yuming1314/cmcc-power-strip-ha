本次改造基于罗总（qlwz）的esp_dc1框架进行移植适配，WEB管理界面与斐讯DC1一脉相承


前言

之前看到罗总（qlwz）给斐讯DC1写的开源固件（esp_dc1）：https://github.com/qlwz/esp_dc1，WEB配置、MQTT自动发现、电量统计、过载保护等功能非常完善。当时就想——这套框架能不能移植到其他ESP8266插排上？

正好手头有几个中移铁通定制的插排，ESP12S + SY7T609计量芯片 + 两个欧姆龙继电器，硬件底子不错，20多块性价比极高。于是参考罗总框架的设计思路，把这个插排适配到了类似esp_dc1的固件体系下，并加入了  HomeKit直连  功能。

     一、硬件规格

| 项目 | 规格 |

| 可控插座 | 两路 |
| 内部结构 | 全铜条线路 |




     二、固件功能详解（对应WEB界面）
先看刷完后的效果，WEB管理界面跟罗总的esp_dc1风格一致，功能也是一脉相承：

       1. WEB首页 - 设备状态总览  

可以看到设备主机名`cmcc_XXXXXX`，WiFi信号强度-66dBm，运行状态一目了然。

下面结合WEB管理界面，逐一介绍各项功能。

      2. 网络设置


- 支持  WiFi扫描  ，点击「搜索WiFi」可列出附近所有热点，选网更便捷
- 支持  静态IP  设置，方便固定内网地址
- 可配置  WEB管理端口  （默认80）和登录密码，提升安全性
- 支持「断开WiFi 10分钟自动重启」功能，防止配网异常时卡死

          3. MQTT设置


- 支持配置MQTT Broker地址、端口、用户名、密码
- 支持自定义  主题前缀  
- 支持  心跳上报间隔  设置
- 支持  Retain（保留消息）   开关
- 支持  Home Assistant MQTT自动发现  ，打开后HA中自动生成实体，无需手动写配置
- 页面顶部会显示MQTT连接状态（已连接/未连接及重连次数）

           4. 开关控制/ HomeKit设置


这是核心控制页面，功能非常丰富：

  开关控制区  
- 「主继电器」和「从继电器」两个开关，点击即可控制对应插座通断
- 当前状态实时显示（开/关）

  电量统计区  
实时显示以下数据：
- 电压（V）
- 电流（A）
- 功率（W）
- 视在功率（VA）
- 无功功率（Var）
- 功率因数
- 今日用电量（kWh）
- 昨日用电量（kWh）
- 总用电量（kWh）
- 统计开始时间

  插排设置区  
-   上电状态  ：可选择「开关通电时断开」「开关通电时闭合」「开关通电时状态与断电前相反」「开关通电时保持断电前状态」四种模式
-   WiFi LED（蓝灯）   ：可设置为常亮/常灭/闪烁/未连接时快闪
-   主动上报间隔  ：设置电量数据上报MQTT的频率（秒）
-   功率波动  ：设置功率变化多少时触发上报（百分比或差值）
-   过载保护  ：自定义功率阈值（W），超出自动断电，0为关闭

  实用工具区  
- 下载HA配置文件
- 重置用电量
- 重启模块 / 重置模块

HomeKit设置


- 激活HomeKit才会显示二维码**
- 显示HomeKit**激活状态**和**配对状态**
- 输入**8位激活码**（格式：XXX-XX-XXX）保存后即可在苹果家庭App中配对
- 支持「重置HomeKit」功能，方便重新配对

   💡 配对方法：打开苹果手机「家庭」App → 点击「+」→「添加配件」→「我没有代码或无法扫描」→ 输入激活码配对。配对成功后即可用Siri语音控制：“Hey Siri，打开主继电器/关闭从继电器”。




     实体按键操作说明

插排上的物理按键支持三种操作方式，方便快速控制：

| 操作方式 | 功能说明 |
|---------|---------|
| 单击 | 切换【主继电器】开关状态（开/关） |
| 双击 | 切换【从继电器】开关状态（开/关） |
| 长按（约5秒） | 重置WiFi，进入配网模式（指示灯快闪） |

   操作时无需打开手机App或网页，直接按插排上的实体按键即可完成日常开关控制，非常方便。

      三、配网与使用

    首次配网
刷机完成后，插排会自动进入AP热点模式，手机搜索WiFi连接后，在浏览器输入`192.168.4.1`进入WEB配置页面（界面与上图一致），设置WiFi名称和密码即可联网。

      联网后访问
插排联网后，在浏览器输入插排的IP地址（如`192.168.1.4`），即可进入WEB管理界面，使用用户名例如`admin`和密码登录（密码在WEB安全设置中修改）。


      四、两种使用方式

      方式一：HomeKit直连（🍎 推荐苹果用户）

- 无需Home Assistant，无需任何中间件
- 苹果家庭App原生控制，响应快、稳定
- 支持Siri语音控制
- 支持iOS控制中心和桌面小组件快捷操作

     方式二：接入Home Assistant

- 在MQTT设置中打开「MQTT自动发现」
- HA中会自动生成两个开关实体和一组电量传感器
- 配合HA的自动化、场景、仪表盘，可以实现更复杂的联动


     五、固件下载与刷机


固件包含两个文件：
- cmcc-homekit.bin — 主固件，激活码根据MAC地址加密生成，一机一码（20元/个）
- cmcm.bin — OTA中转固件

刷机方式：
- 首次刷机：直接用Flash Download Tool烧录 `cmcc-homekit.bin`
- OTA升级：已刷过固件的：先传 `cmcm.bin`，重启后再传 `cmcc-homekit.bin`

  刷机接线  ：

| 插排主板 | USB转TTL |
|---------|----------|
| 3.3V | 3.3V |
| GND | GND |
| TX | RX |

| GPIO0 | GND（短接进入刷机模式） |

       六、注意事项

1.   继电器为5A规格*2个  ，请勿接入大功率设备（总功率建议不超过2500W）
2.   SY7T609为免校准计量芯片  ，功率/电量数据仅供参考，不做计量精度保证
3.   刷机安全  ：刷机时严禁带220V强电操作
4.   仅供个人学习使用  ，严禁用于商业用途
